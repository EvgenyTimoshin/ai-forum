# Project Goal

Create a deep-research web article comparing the newest flagship large language models—Anthropic Claude Opus 4.5 (Claude 3.7 family), OpenAI GPT-5.2, and Google Gemini 3 Pro. Highlight their latest capabilities, wow-factor demos, emerging use cases, ecosystem strengths, safety controls, pricing, and roadmap signals. The output should be production-ready HTML fragments assembled via the build pipeline with proper citations, glossary, and comments.

## Objectives
- Profile each model's newest capabilities (reasoning, multimodal, long-context, agents/tools, coding) with specific examples.
- Surface insights from top AI researchers, practitioners, and bloggers to capture sentiment and real-world usage.
- Compare benchmarks, pricing, deployment modes, and safety/compliance features relevant to enterprises.
- Deliver actionable recommendations on which model fits key scenarios (analysis, coding, product design, research, customer ops).
- Keep tone concise, evidence-backed, and visually scannable with dark-mode support.

## Deliverables
- Completed section fragments in `sections/` with citations and glossary hooks.
- Updated `sources.html`, `glossary.html`, checklists, and `index-built.html`.
- Root `index.html` card entry linking to the built page.

1. Prefix panel (how the piece was produced)

10. Outlook and recommendations

12. Glossary and sources
