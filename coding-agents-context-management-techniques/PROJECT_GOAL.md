The goal of this project is to create a long-form, highly practical blog post on **coding agents** and **best context management techniques** (how to keep an agent effective across long tasks, many files, and many tool calls).

## Target audience
- Software engineers building agentic systems (tools, RAG, memory, planning/execution loops).
- Technical readers who want concrete patterns, checklists, and failure modes (not hype).

## Non-negotiable requirements (from the user)
- Use **real internet sources** (primary docs + reputable research/blogs) and cite them in `SOURCES.md`.
- Write **extensively** and format the final post beautifully using the repo’s modular section-based HTML template.
- Focus on **coding agents** and **best context management techniques** (practical, battle-tested).

## Deliverables
- `index.html` (template-based) + modular section files under `sections/`
- `SOURCES.md` with detailed source analysis and quotable takeaways
- `content.md` as the canonical long-form draft (before sectionization)
- `index-built.html` generated by the build step
- Workflow checklists (`HIGH_LEVEL_WORKFLOW_CHECKLIST.md`, plus any step-specific checklists created later)

## Content goals (what the post must teach)
1. What “coding agents” are (vs. chat assistants) and what makes them succeed/fail in real repos.
2. A mental model of **context as a budget** (token constraints, attention dilution, and relevance).
3. A taxonomy of context types:
   - Working context (task + current constraints)
   - Codebase context (files, architecture, conventions)
   - Execution context (tool outputs, errors, logs)
   - Long-term memory (decisions, preferences, project knowledge)
4. Core context-management techniques, with concrete “how-to”:
   - Task decomposition + explicit state (plans, TODOs, checklists)
   - Progressive summarization (rolling summaries; decision logs)
   - Retrieval (semantic search, file indexing, chunking strategies)
   - “Just-in-time” expansion (fetch detail only when needed)
   - Guardrails (anti-prompt-injection, source-grounding, evals)
   - Token budgeting tactics (what to keep, compress, or drop)
5. A practical playbook for building/operating coding agents:
   - Prompt + system design patterns
   - Memory architecture patterns (short-term vs long-term)
   - Tooling patterns (search/read/edit/build/test loops)
   - Debugging and observability (traces, logs, replay)
6. A “do this tomorrow” checklist for teams adopting agents in CI/dev workflows.
